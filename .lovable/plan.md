# Public FAQ page

## What to build
- Create a public `/faq` page for Rebel Prompt AI with useful answers about accounts, prompts, plans and payments, and getting support.
- Add discoverable links from the public landing page and the signed-in support page, so customers can check answers before submitting a ticket.
- Give the FAQ page its own title and description metadata, matching the existing app style and routing patterns.

## Technical details
- Use a dedicated TanStack file route and standard route links.
- Keep the content static and public; no database or authentication changes are needed.
- Verify the FAQ route, both entry links, and build output.
